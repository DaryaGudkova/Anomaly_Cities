# Анализ качества жизни в городах

В работе исследуются показатели качества жизни в городах на основе данных Numbeo: выполняется сбор данных, предобработка, разведочный анализ, снижение размерности, кластеризация и поиск аномальных городов.

## Состав проекта

- `BHW.ipynb` - основной Jupyter Notebook с полным ходом анализа.
- `М24-514_ГудковаДА_Отчет.pdf` - итоговый отчет по работе.
- `М24-514_ГудковаДА_през.pptx` - презентация с основными результатами.

## Данные

Данные собираются из рейтинга Numbeo:

<https://www.numbeo.com/quality-of-life/rankings.jsp>

В ноутбуке реализован парсер таблицы качества жизни. После загрузки данные сохраняются в файл `numbeo_qol.csv`, который используется на следующих этапах анализа.

Используемые признаки включают:

- `Quality of Life Index`
- `Purchasing Power Index`
- `Safety Index`
- `Health Care Index`
- `Cost of Living Index`
- `Property Price to Income Ratio`
- `Traffic Commute Time Index`
- `Pollution Index`
- `Climate Index`

## Основные этапы анализа

1. Парсинг данных с сайта Numbeo.
2. Загрузка и первичная проверка датасета.
3. Предобработка: обработка пропусков, отбор признаков, масштабирование.
4. Разведочный анализ данных и анализ корреляций.
5. PCA для факторного анализа и интерпретации главных компонент.
6. Кластерный анализ городов:
   - `KMeans`
   - `AgglomerativeClustering`
   - `GaussianMixture`
   - ансамблевая кластеризация
7. Оценка качества кластеризации с помощью метрик `Silhouette Score`, `Calinski-Harabasz`, `Davies-Bouldin` и других.
8. Интерпретация полученных кластеров.
9. Поиск аномальных городов с помощью `KNN`, `Isolation Forest` и `COPOD`.

## Результаты

В работе выделены группы городов со схожими профилями качества жизни. Кластеры интерпретируются через уровень доходов, безопасность, стоимость жизни, экологию, транспортную нагрузку и климат.

По итогам сравнения моделей выбран устойчивый вариант кластеризации, а также построен ансамблевый подход для обнаружения аномальных городов. Практическая интерпретация результатов может использоваться для задач релокации, сравнения городов и оценки рисков.

## Требования

Проект рассчитан на Python 3.11 и Jupyter Notebook. Основные зависимости:

```bash
pip install pandas numpy requests beautifulsoup4 lxml tqdm matplotlib seaborn scikit-learn scipy pyod
```

## Запуск

1. Установите зависимости.
2. Откройте ноутбук:

```bash
jupyter notebook BHW.ipynb
```

3. Выполните ячейки последовательно сверху вниз.

При первом запуске ноутбук обращается к сайту Numbeo и создает локальный файл `numbeo_qol.csv`. Для повторного анализа можно использовать уже сохраненный CSV-файл, если он присутствует в рабочей директории.

## Примечания

- Результаты парсинга могут немного отличаться при повторном запуске, так как Numbeo обновляет данные на сайте.
- Для корректного парсинга требуется интернет-соединение.
- Визуализации и выводы уже сохранены внутри ноутбука.
